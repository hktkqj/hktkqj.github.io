Markdown 指南

📝 笔记 Markdown 写作
📋 本文目录
  1. 标题
  2. 强调
  3. 列表
  4. 链接与图片
  5. 代码
  6. 引用
  7. 表格

Markdown 是一种轻量级标记语言，可以用纯文本格式编写文档，并转换成结构化的 HTML。以下是常用语法速查。

标题

使用 # 符号表示标题级别，# 越多级别越低：

# 一级标题
## 二级标题
### 三级标题
#### 四级标题

强调

**粗体文字**
*斜体文字*
~~删除线~~
**粗体中的 *斜体***

列表

无序列表

- 苹果
- 香蕉
- 橙子

有序列表

1. 第一步
2. 第二步
3. 第三步

任务列表

- [x] 已完成的任务
- [ ] 待完成的任务

链接与图片

[链接文字](https://example.com)
![图片描述](https://example.com/image.png)

代码

行内代码使用单个反引号：

`console.log('Hello, World!')`

代码块使用三个反引号，并可指定语言：

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}
```

引用

> 这是一段引用内容。
> 可以跨越多行。

表格

| 列1   | 列2   | 列3   |
|-------|-------|-------|
| 内容1 | 内容2 | 内容3 |
| 内容4 | 内容5 | 内容6 |

渲染效果：

列1列2列3
内容1内容2内容3
内容4内容5内容6

更多语法请参考 CommonMark 规范。
