概述

本文档库是一个基于纯 HTML / CSS 构建的静态个人文档分享网站，托管在 GitHub Pages 上，无需服务器，无需构建工具，直接编辑 HTML 文件即可更新内容。

目录结构

├── index.html          # 主页（文档目录）
├── css/
│   └── style.css       # 全站样式
├── js/
│   └── docs.js         # 交互脚本
└── docs/               # 文档分类目录
    ├── notes/          # 笔记类文档
    │   ├── index.html

    ├── guides/         # 教程类文档
    │   ├── index.html
    │   ├── getting-started.html
    │   └── how-to-add-docs.html
    └── projects/       # 项目类文档
        ├── index.html
        └── project-alpha.html

本地预览

由于是纯静态页面，可以使用任何静态文件服务器本地预览：

方法一：Python（推荐）

# Python 3
python -m http.server 8080

# 然后在浏览器打开
# http://localhost:8080

方法二：Node.js

npx serve .
# 或
npx http-server .

方法三：VS Code 插件

安装 Live Server 插件，右键 index.html 选择 Open with Live Server。

发布到 GitHub Pages

  1. 将代码推送到 GitHub 仓库的 main 分支。
  2. 进入仓库 Settings → Pages。
  3. 在 Source 中选择 main 分支，根目录 /。
  4. 保存后等待几分钟，即可通过 https://<username>.github.io 访问。
仓库名必须为 <username>.github.io（如 hktkqj.github.io），GitHub Pages 才会自动以根域名发布。
