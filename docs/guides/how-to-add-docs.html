如何添加文档

📖 教程 贡献
📋 本文目录
  1. 向已有分类添加文档
  2. 新建文档分类
  3. 页面模板
  4. 更新侧边栏与主页

向已有分类添加文档

以向 笔记（notes） 分类添加一篇新文档为例：

  1. 在 docs/notes/ 目录下创建新的 HTML 文件，例如 linux-commands.html。
  2. 参考下方的页面模板填写内容。
  3. 在 docs/notes/index.html 的文档列表中添加对应链接。
  4. 在所有页面的侧边栏（<aside class="sidebar">）中添加该链接。
  5. 在主页 index.html 的"最近更新"列表中添加该链接（可选）。

新建文档分类

  1. 在 docs/ 下创建新文件夹，例如 docs/tools/。
  2. 在该文件夹中创建 index.html 作为该分类的目录页。
  3. 在主页 index.html 的分类卡片区域（.category-grid）添加新的分类卡片。
  4. 在所有页面的侧边栏中添加新分类的条目。
  5. 在顶部导航（<nav>）中添加链接（可选）。

页面模板

新建文档时，复制以下模板并替换占位内容：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>文档标题 — 我的文档库</title>
  <link rel="stylesheet" href="../../css/style.css" />
</head>
<body>

<!-- 复制任意已有页面的 header 和 sidebar -->

<main class="main-content">
  <div class="page-header">
    <div class="breadcrumb">
      <a href="../../index.html">首页</a>
      <span>›</span>
      <a href="index.html">分类名</a>
      <span>›</span>
      <span>文档标题</span>
    </div>
    <h1>文档标题</h1>
    <div class="page-meta">
      <span>分类图标 分类名</span>
      <span class="tag">标签</span>
    </div>
  </div>

  <div class="article-content">
    <p>正文内容…</p>
  </div>
</main>

<footer class="site-footer">
  <p>© 2026 hktkqj · 使用纯 HTML / CSS 构建</p>
</footer>

<script src="../../js/docs.js"></script>
</body>
</html>

更新侧边栏与主页

每新增一篇文档，需要在以下位置更新链接：

文件需要更新的位置
所有 HTML 页面侧边栏 <aside class="sidebar">
index.html最近更新列表 .doc-list
index.html分类卡片的文档数量 .doc-count
docs/<category>/index.html分类目录列表 .doc-list
提示：如果文档较多，可以将侧边栏抽取为一个独立文件，用服务端 include 或 JavaScript fetch 动态加载，避免重复维护。
