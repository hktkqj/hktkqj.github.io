项目简介

项目 Alpha 是一个演示性质的个人文档分享网站，展示了如何使用纯 HTML 和 CSS 搭建一个结构清晰、易于维护的静态文档站点，并免费托管在 GitHub Pages 上。

本项目不依赖任何前端框架或构建工具，适合希望快速上线个人文档站点的用户。

主要功能

  • 📋 主页文档目录，分类展示所有文档
  • 🗂️ 侧边栏导航，支持多级分类
  • 🔍 实时关键词过滤搜索
  • 📱 响应式布局，适配手机和桌面
  • 🏷️ 标签系统，标注文档属性
  • 📝 面包屑导航，清晰展示当前位置
  • 📖 文章内目录（TOC），方便长文档导航

技术栈

技术用途版本
HTML5页面结构—
CSS3样式与布局（Flexbox/Grid）—
Vanilla JS侧边栏交互、搜索过滤ES5+
GitHub Pages静态站点托管—

使用说明

  1. Fork 或 Clone 仓库到本地。
  2. 按照如何添加文档教程添加自己的内容。
  3. 推送到 GitHub，在仓库 Settings 中启用 Pages 即可上线。
完整的部署说明请参考快速开始文档。
